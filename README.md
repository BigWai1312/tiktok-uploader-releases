# 像素 TikTok 上传助手

Windows x64 桌面上传助手安装包发布仓库。

[下载最新安装版](https://github.com/BigWai1312/tiktok-uploader-releases/releases/latest)

## 安装和使用

1. 在 Releases 页面下载 `TikTokUploader-版本号-Setup.exe` 并安装，无需另装 Node.js 或 .NET。
2. 使用用户名、密码注册，无需邮箱验证码；已有邮箱账号可以继续登录。
3. 启动 ixBrowser，在目标窗口中完成 TikTok 登录。
4. 在助手中关联窗口、添加视频、填写标签，并选择每条视频的目标窗口。
5. 检查上传流程设置，然后开始上传。

用户名为 3-32 位英文、数字或下划线，密码至少 6 位。新账号余额为零；未绑定邮箱的账号忘记密码时需联系管理员。

勾选“记住账号和登录状态”后，下次启动自动读取本机加密会话并向服务器恢复登录，无需重复输入密码。上传仍需服务器验证有效会话和余额。

新安装默认开启自动填写标签、AI 内容标记、展开设置、不添加音乐和提交后继续下一条。自动发布默认关闭；开启后会实际提交视频。非 AI 视频请关闭 AI 内容标记。关闭“不添加音乐”后需要人工选曲。

## 数据与卸载

- 安装版账号、设置、队列、日志及加密登录凭据保存在 `%LOCALAPPDATA%\LiZiYang\TikTokUploader\data`。
- 默认视频归档保存在 `%LOCALAPPDATA%\LiZiYang\TikTokUploader\VideoRecords`，可在设置中更改。
- 开发版使用独立的 `%LOCALAPPDATA%\LiZiYang\TikTokUploader-Dev`，不读取安装版凭据。
- 开始菜单同时提供“启动应用”和“卸载”；安装目录内也有 `卸载.exe`。
- 覆盖安装保留数据。卸载默认保留个人数据；取消勾选“保留账号、设置、队列、日志和默认视频归档”会清除当前用户的软件数据及旧安装目录内的数据。
- 自定义视频目录和 ixBrowser 的窗口资料不会被卸载清理。加密凭据绑定 Windows 用户，不能保证跨电脑解密。

`LiZiYang` 是应用的数据命名空间；`%LOCALAPPDATA%` 根据当前电脑的 Windows 用户确定，不是开发电脑的固定用户路径。

## 更新和反馈

通过 Releases 下载新版并覆盖安装；安装前退出正在运行的程序。客户端后台自动更新尚未接入。

每个安装包附带 SHA-256 校验文件。请在 Issues 中描述软件版本、复现步骤和经过脱敏的截图，不要提交账号资料、令牌、代理密码或视频。

安装包未配置可信数字签名，Windows 可能提示“未知发布者”。本仓库只发布安装包、版本说明和校验文件，项目源码保存在私有仓库。代码混淆不能保证程序不可破解。

每个版本的测试范围与已知限制见对应 Release。真实 TikTok 上传、发布及支付扣款不属于自动化测试范围。
